# Установить и начать игру

## Какие расширения нужны

| Компонент | Для чего | Установка |
| --- | --- | --- |
| **WorldMemory 0.3.3 или новее** | Архив L0, восстановление истории и отдельная справочная WI-книга | `https://github.com/Ilya626/Extension-WorldMemory` |
| **Russian WI Forms 0.1.3 или новее** | Русские склонения и спряжения в штатных ключах WI | `https://github.com/Ilya626/Extension-RussianWI` |

WorldMemory работает самостоятельно. Russian WI Forms нужен для словоформ, но карточка и обычные буквальные ключи ST работают и без него. Словарь около 11 МБ уже лежит в репозитории; Python и загрузка локальной модели не нужны.

Summaryception, MemoryBooks, MarkUps, Tavern Helper и ST Vector Storage не являются зависимостями WorldMemory. Сама сторонняя карточка может иметь свои зависимости — проверяйте инструкцию её автора. Не запускайте Summaryception вторым владельцем памяти того же чата.

## Какие комбинации использовать

- **WorldMemory + Russian WI Forms** — новая система: подбор прошлой истории и отдельный native WI с русскими словоформами.
- К ней можно добавить **[MarkUps](https://github.com/Ilya626/Extension-MarkUps)** для текущих видимых списков/квестов и скрытых заметок. Модель обновляет их командами внутри своего обычного ответа, без отдельной фоновой генерации.
- **[Наш Summaryception](https://github.com/Ilya626/Extension-Summaryception) + Russian WI Forms**, по желанию MarkUps — альтернативный вариант с памятью в слоях L0–L4. Embeddings для самостоятельного Summaryception не нужны.
- **Russian WI Forms и MarkUps** работают и без системы памяти, вместе или по отдельности.

Текущий WorldMemory и Summaryception — два альтернативных владельца памяти. При переходе WorldMemory импортирует старый архив и отключает Summaryception; оставлять оба активными для одного чата не следует. Инструкции старого WorldMemory 0.2 companion не относятся к текущему standalone 0.3.3. Перечень комбинаций описывает назначение и границы интеграции, а не отдельный живой прогон всех расширений вместе.

## Установка и обновления с GitHub

1. В ST откройте **Extensions → Install extension**, вставьте адрес WorldMemory из таблицы и установите.
2. Тем же способом установите Russian WI Forms. Перезагрузите страницу.
3. В Russian WI Forms дождитесь **Словарь готов**. Обработка всех подключённых книг включена по умолчанию. Выдуманные имена, которых нет в словаре, требуют ручных форм или явных ключей; аддон не угадывает их склонение.

Обновляйте через штатный менеджер расширений ST, затем перезагружайте страницу. Установка по Git-ссылке позволяет пользоваться этим обновлением. ZIP/ручная копия файлов не создаёт Git-установку для штатного updater; для него нужна установка по ссылке. Перед обновлением экспортируйте **WorldMemory → Portable backup → Export backup** и сам чат через ST. Настройки подключения сохраняются.

## Три подключения

1. **Игровая модель** настраивается в обычном подключении ST.
2. **Summarizer connection** в WorldMemory — модель для фоновой подготовки памяти. Можно выбрать текущее подключение ST, Connection Profile или собственный API.
3. **Search and embeddings** — API для семантического поиска. Выберите **API embeddings**, формат, URL, ключ и именно embedding-модель. Пример поддерживаемого формата: **Google / Gemini embeddings**, `gemini-embedding-001`, **768** измерений. Для OpenAI-совместимого endpoint выберите соответствующий формат и поддерживаемую провайдером embedding-модель.

Embedding URL/key автоматически наследуются только из собственного **OpenAI-compatible API** подключения суммаризатора WorldMemory. При использовании текущего ST-подключения или Connection Profile укажите их явно. Чатовая модель не заменяет embedding-модель. Один провайдер может обслуживать все три подключения, если у него есть нужные API.

Для API-варианта не нужны локальные веса, отдельный сервер моделей или reranker. Тексты индекса и поисковые запросы отправляются выбранному embedding-провайдеру. Без embeddings остаётся поиск истории по словам; предупреждение о fallback означает, что семантический поиск не сработал.

## Импорт подготовленного комплекта

Приватные карточки, чаты и книги не входят в этот репозиторий. Если вы получили отдельный комплект с файлами `1-Character.json` и `2-Continue.jsonl`:

1. Импортируйте `1-Character.json` как персонажа. Согласитесь на импорт встроенной книги; если вопроса нет — **More… → Import Card Lore**.
2. У этого персонажа импортируйте `2-Continue.jsonl` через список чатов. Продолжайте **импортированный чат**, а не новый пустой. Если архив включён в metadata чата, отдельно импортировать память не требуется.
3. Включите **Enable WorldMemory**. В **Advanced history insertion → Insert retrieved history** выберите **Immediately before chat history**: восстановленная история будет непосредственно перед перепиской.
4. Проверьте **L0 archive** и подключённую авторскую WI-книгу. Не подключайте вторую копию той же книги. Optional memory backup нужен только для восстановления: его импорт заменяет текущую память чата.
5. Для первого просмотра можно включить **Advanced history and packet settings → Pause automatic summarization** и выключить **World Info · entity reference → Prepare and apply WI after saving L0**. Поиск готовой памяти продолжает работать. После настройки суммаризатора снимите паузу для дальнейшего накопления; автоматическое обновление WI включается отдельно.

## Размер контекста и большая авторская книга

**Full RP prompt target** — мягкий ориентир, не ограничитель запросов ST. **Raw tail** и **Max history tokens** задаются отдельно; они не ограничивают размер сохранённого архива.

Авторский Constant WI всё равно проходит через штатный бюджет WI в ST. При слишком маленьком бюджете даже постоянная запись может не войти в запрос. Настройка контекста модели должна вместить карточку/инструкции, активный WI, хвост, восстановленную историю и резерв ответа. Проверьте штатный WI token budget и token budget cap: маленький cap может отменить увеличение процентного бюджета.

Для необычно большой неизменённой книги может потребоваться 48–64k вместо обычного ориентира 24k. Это свойство содержимого карточки, а не требование аддона для всех игр. Смотрите предупреждения ST о WI и фактический промпт; повышение ориентира WorldMemory само по себе не увеличивает контекст API и бюджет WI.

## Что считать готовым

Версия 0.3.3 — preview для ручной игры. Проверяйте важные воспоминания и новые автоматические WI-справки: модель может ошибаться в деталях, условиях и тождестве персонажей. Реальный телефонный запуск локальной Gemma ещё не квалифицирован; он не нужен для стандартного варианта с API embeddings.
