# World Memory

[English instructions](README.md)

**0.2.1 · альфа.** Профили персонажей и справочные записи World Info по истории Summaryception. Дополнительно — адресуемая история: краткая последовательность сцен раскрывает нужные исходные обмены прямо на их хронологических местах.

Аддон делает **отдельные запросы к модели через настроенное подключение Summaryception**. Они могут дополнительно оплачиваться провайдеру. Нарративные резюме Summaryception расширение не переписывает.

## Быстрый старт

1. Установите или обновите [Summaryception до 5.5.4-local.21 или новее](https://github.com/Ilya626/Extension-Summaryception). В других форках может не быть нужного API для этого аддона.
2. Для русских чатов установите [Russian WI Forms](https://github.com/Ilya626/Extension-RussianWI). Это необязательное дополнение: обычный ключ `меч` сможет распознавать словарные формы вроде `мечом`.
3. В ST откройте **Расширения → Install extension** и вставьте:

   ```text
   https://github.com/Ilya626/Extension-WorldMemory
   ```

4. Перезагрузите ST, откройте чат персонажа и настройки **World Memory**. В **Main characters to always track** перечислите главных персонажей, по одному на строку:

   ```text
   Мира
   Антон
   ```

5. Сохраните резюме L0 в Summaryception или нажмите **Update memory now**, чтобы обработать уже сохранённые пакеты. Результат доступен в **Characters**, **Other records and sources** и через **Open lorebook**.

Автообновление и **Always include main character profiles** включены по умолчанию. Обновляйте аддон через штатное управление расширениями ST, затем перезагружайте страницу. Манифест разрешает автоматическое обновление там, где это допускает ST.

## Небольшой пример

Выдуманная сыгранная сцена: *Антон, смотритель мастерской, одолжил Мире латунный ключ до утра. Мира попробовала открыть шкаф, но замок не открылся.* Подходящие профили:

| Запись | Пример справочного текста |
| --- | --- |
| Мира — персонаж | Взяла у Антона латунный ключ до утра. Пробовала открыть шкаф; попытка не удалась. |
| Антон — персонаж | Смотритель мастерской. Одолжил Мире латунный ключ до утра. |
| Латунный ключ — предмет | Сейчас одолжен Мире Антоном. В описанной попытке шкаф не открылся; причина неизвестна. |

Это пример нужного результата, а не гарантированный ответ модели. Попытка не должна становиться успехом. Тайны карточки и ещё не сыгранные события не считаются доказательствами. Без подтверждённых сведений персонаж может остаться пустой заготовкой: одно имя не задаёт биографию.

## Штатный World Info

Аддон создаёт **отдельную штатную книгу текущего чата**. Существующая привязка книги чата и исходные лорбуки сохраняются. Записи добавляются в нативное сканирование через `WORLDINFO_ENTRIES_LOADED`; менять прежнюю привязку или вручную подключать созданную книгу не требуется.

Главные профили по умолчанию используют стратегию ST **Constant**. Остальные записи активируются обычными ключами. Russian WI Forms расширяет словоформы при сканировании; регулярные выражения в книгу не записываются. Действуют штатный бюджет WI, отключение записей и правила вставки. Constant не отменяет бюджет.

По умолчанию выбрана позиция **In-chat @ Depth**, глубина **2**. Доступны также Before/After Main Prompt и Before/After Author's Note. Итоговый порядок зависит от настроек промпта ST.

## Обновление и ручное управление

- **Автообновление** реагирует на сохранение памяти и обрабатывает новые или изменённые пакеты L0. Исходные пакеты доступны и после переноса резюме в старшие слои Summaryception.
- **Update memory now** повторно обрабатывает доступные сохранённые пакеты, чьи источники не устарели, включая уже обработанные. Запросов может быть несколько; пересборка затронутых записей тоже может потребовать обращения к модели.
- **Stop** отменяет текущую работу. Уже сохранённые пакеты остаются; завершённая работа не откатывается.
- Вклады фактов связаны с ID пакетов и исходных сообщений. Удаление пакета в Summaryception убирает его автоматические вклады при следующем обновлении. Затронутые автоматические записи пересобираются из оставшихся вкладов или удаляются, если вкладов больше нет. Ручные записи сохраняются.
- Изменение, удаление или свайп исходного сообщения делает связанные пакеты устаревшими. Сначала регенерируйте эти резюме в Summaryception, затем обновите WI.
- Перед самостоятельным ведением записи нажмите **Keep manual**. Аддон также замечает изменения сгенерированного названия, основных ключей, текста, Constant и отключения записи. Защищённые записи пропускаются. **Allow automatic updates** снова разрешает их обновление. Вручную добавленные штатные записи не становятся собственностью автоматики.

## Настройки запросов по умолчанию

| Настройка | Значение | Что означает |
| --- | --- | --- |
| Maximum response tokens | **4096** | На один ответ; **0** наследует настройку ответа Summaryception. |
| Original-message detail tokens per packet | **4000** | Дополнительные исходные сообщения целиком, начиная с новых. Полное сохранённое резюме L0 передаётся всегда. |
| Prior entry-fact tokens per request | **6000** | Сохранённые факты для извлечения; сначала рассматриваются главные профили. Это не предел всего промпта или любой пересборки. |
| Target tokens per entry | **160** | Ориентир краткости, а не жёсткий предел размера. |

Язык может следовать источнику либо быть задан как English/Русский. Контекст модели по-прежнему ограничен: полное резюме и индекс записей тоже занимают место; большая пересборка может превысить бюджет фактов запроса извлечения.

## Копии чатов и резервные копии

Ветка или переименованный/скопированный чат, определённый по другому ID чата, получает собственную книгу при обновлении. Записи аддона копируются без дальнейшей записи в книгу исходного чата. Проверьте связи с источниками после обрезки сообщений.

**Export backup** сохраняет книгу, список персонажей и связи пакетов. **Import backup заменяет содержимое книги World Memory текущего чата**; предварительно экспортируйте текущую версию, если она нужна. Копия другого чата импортируется как защищённые ручные записи, а старые связи вкладов очищаются. Пакеты Summaryception другого чата при этом не переносятся. Штатный JSON лорбука можно импортировать через редактор World Info ST, но простое подключение такой книги не устанавливает автоматическое владение и связь с чатом.

## Ограничения альфы

Проверяйте важные результаты через **Open lorebook**. Извлечение, различение сущностей и полнота зависят от модели: пропуски возможны. Группы истории следуют границам обменов и токенному объёму; они не гарантируют точные смысловые границы сцен. Общие имена и широкие ключи могут активировать неподходящую запись. Длинная история может потребовать много платных запросов. У старых резюме могут отсутствовать связи с исходниками. Семантическая активация WI и локальный реранкер не реализованы. Совместимость со всеми версиями ST, провайдерами и сторонними аддонами не обещается.

## Адресуемая история L0 / L0′

В **History with selective detail** включите **Build and use addressable L0 / L0′ history**, затем нажмите **Update memory now**. По умолчанию режим выключен. Старые резюме и пользовательские промпты сохраняются.

Тот же запрос, который обновляет WI, получает весь исходный пакет с точными ID сообщений. Код группирует целые обмены; модель возвращает для каждой группы подробный эпизод L0, короткую причинную опору L0′ и поисковые ключи. В этом режиме лимит дополнительных исходников 4 000 не применяется: для точной адресации нужны все источники пакета. Запрос и ответ становятся больше; для крупных пакетов разумно выставить 8 192 выходных токена.

Перед RP-ответом текущий пост и предыдущий ответ ищутся по подробным эпизодам и исходным обменам. Затем собирается одна история в исходном порядке:

```text
краткая сцена 1 → исходный обмен сцены 2 → краткая сцена 3 → живой чат
```

Частичный исходный фрагмент сохраняет короткую рамку сцены. Если исходники раскрывают эпизод целиком, его резюме заменяется ими. Используется место вставки памяти из Summaryception. Исходные сообщения не раскрываются в чате; живой хвост и Blind Zone сохраняются. WI сканируется и вставляется штатно, отдельно.

Бюджеты по умолчанию: **4 000 токенов** краткой истории и ещё **4 000** подробностей. Слишком большой обмен пропускается целиком; меньшие кандидаты ещё могут войти. Если даже краткая история не помещается, связи устарели или сборка недоступна, работает обычная послойная память Summaryception. Бесконечное рекурсивное ужатие L0′ пока не реализовано.

### Простая структура после поста

При включённом **Ask the RP model for a hidden scene / keys / carry block** модель получает инструкцию заканчивать пост так:

```text
Антон отдаёт Мире ключ. «Верни до утра».
<memory_hint>
anchor: Антон одолжил Мире ключ
keys: Антон; Мира; латунный ключ; одолженный ключ
carry: вернуть ключ до утра
</memory_hint>
```

Ровно три коротких поля: сцена, поисковые ключи, незавершённое условие. Для пустого поля — `-`. Отдельного вызова модели на этом шаге нет; расходуются дополнительные выходные токены. Блок скрывается при стриминге и после получения отделяется от текста в метаданные выбранного сообщения/свайпа. Это подсказки поиска, а не новые доказанные факты. Пропущенная или неправильная разметка не отменяет RP-ответ.

### Поиск, хранение и обслуживание

По умолчанию поиск локальный, по словам. **Russian WI Forms 0.1.2+** даёт ему словарные леммы, а штатному WI — прежние словоформы. По желанию можно включить embeddings: сначала настроить поддерживаемого облачного провайдера в ST Vector Storage, затем отметить **Also search using ST's configured hosted embeddings**. Используются штатные серверные маршруты ST и его ключ; возможна оплата провайдеру. Модели на телефон не скачиваются, реранкер не запускается. Ошибка embeddings оставляет поиск по словам. Это не переключатель семантического включения WI.

Первичная индексация может занять заметно больше обычного поиска. В 0.2.1 таймаут составляет 120 секунд бездействия и обновляется после каждого ответа векторного сервера; прежнее общее ограничение 10 секунд убрано. Готовые векторы используются повторно.

Оригинал чата и архив Summaryception остаются основанием. Подсказка и отпечаток текста хранятся в метаданных выбранного варианта сообщения. Подробные/краткие эпизоды — в метаданных чата, с ревизией пакета и исходными ID. Отдельной БД текстовой памяти нет. Векторы кэшируются средствами ST; устаревшие записи удаляются при следующем векторном подборе.

Правки, свайпы, удаление и регенерация сбрасывают готовый контекст. Удалённые пакеты очищаются при следующем обновлении памяти; изменённые перестраиваются по актуальным источникам. Ошибка дополнительной разметки сохраняет L0 и пригодные эпизоды той же ревизии, без бесконечных автоматических повторов. **Update memory now** позволяет повторить явно.

Экспорт World Memory включает эпизоды. Для полного переноса экспортируйте также сам чат ST: там оригиналы и подсказки свайпов. Лорбук один историю не восстанавливает. Импорт бэкапа другого чата сохраняет справки как ручные и очищает старые связи истории. Отключение режима возвращает обычную вставку Summaryception.
